**Characteristics of the instrument:**

The ArjoHuntleigh Healthcare Enterprise 9000, 9100, 9000X and the Citadel are hospital beds incorporating a Class III, mains operated, self-indicating, Non-Automatic Weighing Instrument having the following characteristics:

ArjoHuntleigh Healthcare Enterprise 9000, 9100 and 9000X

Maximum capacity (Max) 250 kg
Minimum capacity (Min) 10 kg
Scale interval (e =) 0.5 kg
Number of divisions (n) 500

ArjoHuntleigh Healthcare Citadel

Maximum capacity (Max) 270 kg
Minimum capacity (Min) 10 kg
Scale interval (e =) 0.5 kg
Number of divisions (n) 540

<u>Main features:</u>

The CDI-1600 indicator has the following features:

- Hospital bed, with contour control and weighing functions.
- Four load cells.
- Safety sides incorporating attendant controls, including weighing control buttons. Identical weight displays and associated control buttons are on both sides of the bed.

<u>Devices:</u>

- Semi-automatic zero setting device.
- Verification scale interval 0.5 kg, but with extended indicating device temporarily giving interval of 0.1 kg.
- "BED EXIT" alarm function if weight decreases to 50% or less.
- "AUTO-COMP" function that allows the weight to be held steady while equipment is added (see Section 2.2.2).

**Technical characteristics**:

<u>Power supply</u>

The instrument operates on a 230 V AC supply with an optional battery back-up.

<u>Load cells</u>

The four load cells are each a Vishay Tedea Huntleigh shear beam load cell model 3410 with a capacity of 1000 lb, or each a Zemic (Zhonghang Electronic Measuring Instruments Co Ltd) shear beam load cell model H8C with a capacity of 500 kg.

<u>Software</u>

The software is installed as compiled code, as an executable file, and as such cannot be modified using common software tools. Any modification to the software can only be carried out by an approved technician.

The verification information can be found on the side of the weighing module (QLCI) on a label bearing the following information, software number and version number. A tamper proof label is also used to seal the QLCI lid to prevent un-authorised calibration or re-programming of the weighing module.
