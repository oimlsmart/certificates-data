# Descriptive annex

The D-Legal digital indicator consists of a D-Legal program running on a Windows PC
When the D-Legal program is started a window appears in the most upper part of the screen showing the weight. This window cannot be closed. Double click on this window will start the standard digital indicator window.

D-Legal is intended for use with a DINI Argeo weight transmitter. The connection of the weight transmitter to the PC is done using either USB, ethernet, serial port or wireless. The connecting cable or wireless connection is with an electronic board, that secures the pairing of the weight transmitter and D-legal software via a special Dini Argeo protocol.

## Characteristics

Type: D-Legal
Accuracy Class: III and IIII
Weighing ranges: Single-interval, multi-interval or multi-range
Maximum number of verification scale intervals(n): ≤ 10000 per interval/range up to 3 intervals/ranges
Maximum tare effect: -Max

## Devices

The D-Legal program has the following devices:

- Semi-automatic zero-setting
- Semi-automatic subtractive tare weighing
- Preset tare device
- Data storage device
- Indicators for:
  - Motion
  - Zero
  - Gross / Net
  - Preset tare
  - Weighing unit

## Secondary display

The D-Legal program can alternatively be configured as a secondary display for a Dini Argeo indicator. In this configuration the zero and tare keys are disabled.

## Software

The D-Legal software can only be activated on a PC by the manufacturer using a special software key that pairs the weight transmitter and the D-Legal software permanently and uniquely.
