**DESCRIPTIVE ANNEX**

<u>Characteristics</u>:

This family of instruments is designated the ZQ375 Checkweigher and comprises the Torsion base and Diamond base models. The instruments are Class III, mains or battery-powered, self-indicating, non-automatic weighing instruments, and are not designed for direct sales to the public.

<u>Main features</u>:

&ensp;&ensp;–&ensp;ZQ375 Indicating Device (fully described in R76/2006-A-GB1-20.07)
&ensp;&ensp;–&ensp;BSF / BSG Torsion or BS Diamond base stainless steel load receptor
&ensp;&ensp;–&ensp;Stainless Steel Column
&ensp;&ensp;–&ensp;Optional ZQ-BAT battery box
&ensp;&ensp;–&ensp;Optional ZQ-OPTO interface box (with or without beacon assembly)

<u>Devices</u>:

&ensp;&ensp;–&ensp;Semi-automatic zero setting (≤ 4% Max)
&ensp;&ensp;–&ensp;Zero tracking (≤ 4% Max)
&ensp;&ensp;–&ensp;Semi-automatic subtractive tare weighing
&ensp;&ensp;–&ensp;Pre-set tare
&ensp;&ensp;–&ensp;Recall of Gross indication when tare is active
&ensp;&ensp;–&ensp;Determination of stability of equilibrium
&ensp;&ensp;–&ensp;Indication of stability of equilibrium
&ensp;&ensp;–&ensp;Checking of display
&ensp;&ensp;–&ensp;Printing
&ensp;&ensp;–&ensp;PLUs
&ensp;&ensp;–&ensp;Alibi storage device
&ensp;&ensp;–&ensp;Gravity compensation
&ensp;&ensp;–&ensp;Real time clock
&ensp;&ensp;–&ensp;Command via external device (PC)
&ensp;&ensp;–&ensp;Simple checkweighing (Sim375)
&ensp;&ensp;–&ensp;Mid-level checkweighing (Mid375)
&ensp;&ensp;–&ensp;Advanced checkweighing (Adv375)
&ensp;&ensp;–&ensp;Percentage checkweighing (Per375)
&ensp;&ensp;–&ensp;Grading checkweighing (Grad375)
&ensp;&ensp;–&ensp;Gross, Net, Tare, Preset tare, Print, Zero, Motion, Accumulation, Over/Under weight and Network indicators

<u>Load cell</u>:

Torsion Base (BSF Series):

The load cell is an HBM Stainless Steel Single Point Load cell, model PW15AHC3MR, capacities as per following table.

Torsion Base (BSG Series):

The load cell is a Vishay Stainless Steel Single Point Load cell, model 1130, capacities as per following table.
