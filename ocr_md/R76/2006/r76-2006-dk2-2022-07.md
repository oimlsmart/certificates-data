**Descriptive annex**

**Characteristics**

- Type: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;ID510 / ID511 / ID551PN
- Accuracy class &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;III and IIII
- Single interval
- Maximum capacity &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;≤ 300 000 kg
- Maximum number of verification scale intervals: &nbsp;&nbsp;6000
- Maximum tare effect: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;-Max
- Fraction factor &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;p’I = 0.5
- Minimum input voltage per VSI: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;≥1 µV
- Excitation voltage: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;5 VDC
- Circuit for remote sense: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Yes
- Minimum input impedance: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;43 ohm
- Maximum input impedance: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1100 ohm
- Maximum cable length to junction box: &nbsp;10523 m/mm²
- Temperature range. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;-10 °C to +40 °C
- &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Power supply: &nbsp;&nbsp;&nbsp;&nbsp;100-240 VAC, 50/60 Hz, or 24 VDC not to be supplied from DC mains

**Software**

The approved software is R1.01, dated 2018/01/29<br>
This information is displayed at power up.

**Devices**

- &nbsp;&nbsp;Initial zero setting device (≤ 20% of Max)
- &nbsp;&nbsp;Semi-automatic zero setting device (≤ 4% of Max)
- &nbsp;&nbsp;Zero tracking device (≤ 4% of Max)
- &nbsp;&nbsp;Semi-automatic subtractive tare balancing device
- &nbsp;&nbsp;Zero indicator
- &nbsp;&nbsp;Net indicator
- &nbsp;&nbsp;Stable weight indicator
- &nbsp;&nbsp;Weighing of unstable items
- &nbsp;&nbsp;Totalisation (except for ID551PN)
- &nbsp;&nbsp;Indication of active scale (ID551PN)
- &nbsp;&nbsp;Manual checkweighing (ID511)
