## Software

The software version is displayed on WX/WXS/CST/WTS as part of the turning off sequence. On PC5/PC5S/PC5H/PC5SH/PC6/PC6S/PC6H/PC6SH it can be displayed by pressing the "Tare" and "5" keys simultaneously.

The approved software versions are:

WX / WXS / CST / WTS version 100115 PC5 / PC5S / PC5H / PC5SH / PC6 / PC6S / PC6H / PC6SH version 200115
