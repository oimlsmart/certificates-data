## Descriptive annex

**Characteristics**

Type:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;VT200 / VT220 / VT300 / VT300D  
Accuracy class:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;III  
Weighing range:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Single-interval, multi-interval (up to 2 intervals), multi-range (up to 2 ranges)  
Maximum capacity (Max):&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1 kg to 990,000 kg  
Verification scale interval (e<sub>i</sub> =):&nbsp;&nbsp;Max/n  
Maximum number of Verification Scale Intervals (n<sub>i</sub>):&nbsp;&nbsp;≤ 10000  
Maximum subtractive tare effect:&nbsp;&nbsp;&nbsp;-Max  
Fractional factor:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;p'i = 0.5  
Minimum input voltage per VSI:&nbsp;&nbsp;&nbsp;&nbsp;0.25 μV  
Excitation voltage:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;5 VDC  
Circuit for remote sense:&nbsp;&nbsp;&nbsp;present on the model with 7-terminal connector  
Minimum input impedance:&nbsp;&nbsp;&nbsp;&nbsp;29 ohm  
Maximum input impedance:&nbsp;&nbsp;&nbsp;&nbsp;2000 ohm  
Mains power supply:&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;110-240 VAC, 50/60 Hz, or 12-24 VDC. Internal rechargeable battery (optional).  
Operational temperature:&nbsp;&nbsp;&nbsp;&nbsp;-10 °C to +40 °C  
Maximum 6-wire cable length between indicator and junction box:&nbsp;&nbsp;&nbsp;1564 m/mm²

**Software**

The version of the software is displayed during the power-up sequence of the instrument.  
The version appears in this form: XXXX_Y Z.Q dd-mm-yy  
XXXX indicates the type designation of the instrument  
Y is the language of the user interface  
Z is the application  
Q is a reference code for the software  
dd-mm-yy is the firmware date and acts as version control.  
The approved software version 23-01-18  

**Interfaces**

- RS232
- RS485
- USB (slave)
- Analogue output
- Digital inputs/outputs
