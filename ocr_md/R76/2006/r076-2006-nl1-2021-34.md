Software:

- The checksum will be displayed at start-up, or after pressing the key sequence:
  - Press the [Shift] and [Function F] keys to enter the execution menu from weighing mode;
  - Shift to " 7.ProG.no " using the [Direction] keys "↑" and "↓";
  - Press [Enter] key 3 times to display the display unit checksum;
  - Press [Enter] key one more time to display the load platform checksum;
  - Press [Enter] key one more time to return to the state of weighing.
