**The software consists of a model depending part with an identification and a common software with a version number.**

The software identification is displayed during the power-up sequence of the instrument and shall have the following values.

| MODEL NAME | APPLICATION | SOFTWARE IDENTIFICATION |
|------------|-------------|------------------------|
| VGM | WEIGHING | CE020 |
| VGW | CHECKWEIGHING | CE004 |
| NGP | PRICE COMPUTING | CE005 |
| VGC | PARTS COUNTING | CE006 |

| VDW | CHECKWEIGHING | CE012 |
| VDP | PRICE COMPUTING | CE013 |
| VDC | PARTS COUNTING | CE014 |
| VOM | WEIGHING | CE007 |
| VOWK | CHECKWEIGHING | CE008 |
| VOP | PRICE COMPUTING | CE009 |
| VOC | PARTS COUNTING | CE010 |
