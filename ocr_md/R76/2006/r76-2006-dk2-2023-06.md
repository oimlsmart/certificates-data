**Descriptive annex**

**Characteristics**

Type: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;BNT300A / BNT600A / BNT1200A / BNT3000A / BNT300B /
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;BNT600B / BNT1200B / BNT3000B

Accuracy Class: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;II

Weighing ranges: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Single-interval

Maximum capacity (Max): &nbsp;&nbsp;&nbsp;&nbsp;300 g to 3000 g

Minimum capacity (Min): &nbsp;&nbsp;&nbsp;&nbsp;300g model: 20 x e
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;600g models: 20 x d
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1200g/3000g models: 50 x e

Maximum number of
verification scale intervals(n): &nbsp;&nbsp;6000

Verification scale interval (e=): &nbsp;&nbsp;0.05 g to 1 g

Maximum tare effect: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;-Max

Operating temperature range: &nbsp;+5 °C / +40 °C

Power supply: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;12 VDC using external AC/DC adapter intended for 100-240
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;VAC, 50/60 Hz

**Software**

The approved software version of the indicator is. &nbsp;&nbsp;&nbsp;&nbsp;1.02

**Devices**

- Initial zero setting device (≤ 20% of Max)
- Semi-automatic zero setting device (≤ 4% of Max)
- Semi-automatic subtractive tare device
- Printing device
- Auxiliary indicating device, d=0.1e (models with verification scale interval e = 1×10<sup>k</sup> g only)
- Extended indicating device, d=0.1e (models with verification scale interval e ≠ 1×10<sup>k</sup> g)
- Unit toggling device, only g (gram) and ct (metric carat) are allowed.
- Stable equilibrium, Zero and Net indicators.

**Interfaces**

Communication interfaces:

- RS232

The interface does not have to be secured.
