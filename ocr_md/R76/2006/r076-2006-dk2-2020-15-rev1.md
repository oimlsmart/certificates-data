**Software**

The software is separated in weighing software, application software, printing software and keyboard software.

The software version of the different software's is shown under system settings in the menu.

The approved software versions are,  
weighing software <sup>*</sup>): &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;V1.10 or V2.10  
application software <sup>*</sup>): &nbsp;&nbsp;&nbsp;A1.xx.yy(z)  
screen keyboard: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;K1.xx  
printing software: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;P4.01.xx  
<sup>*</sup>) part of legal relevant software.  
Where xx and yy can be 00 to 99, while z can be not present or a to z.
