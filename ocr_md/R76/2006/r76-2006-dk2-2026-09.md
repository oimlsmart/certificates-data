**Software**

The scales have software separation. The legally relevant software version is 1.11 or 1.12 or 2.00, and the application software has version 1.xx(y), where xx can be 00 to 99, and y can be a to z or blank.
The application software version is displayed during the power-up sequence of the instrument.
The legal relevant software version can be displayed the following way:
APP/LPP: by pressing the “SAVE” key during the power-up sequence of the instrument.
APW/LPW: by pressing the “PLU” key during the power-up sequence of the instrument.
APC/LPC: by pressing the “SMPL” key during the power-up sequence of the instrument.

**Devices**

- Semi-automatic zero-setting, range: ±2 % of Max.
- Automatic zero-tracking, range: ±2 % of Max.
- Initial zero-setting range: ±10 % of Max.
- Semi-automatic subtractive tare
- Semi-automatic tare
- Preset Tare (Combined with the PLU’s)
- Extended resolution (only APW / LPW / APC / LPC)
- Price look up table (PLU)
- Unit Weigh look Up table
- Totalization (only APP/LPP)
- Check Weighing device (only APW / LPW / APC / LPC)
- Percentage weighing (APW/LPWonly)
- Printing (external printer connected to interface)
- Counting device (APC/WPC only)
- Gravity compensation

**Interfaces**

- RS-232 interface.
- USB interface (Optional)
- Ethernet interface (optional)
- Wi-Fi interface (optional)
- Bluetooth interface (optional)
- RJ11 (Cashdrawer, optional)
