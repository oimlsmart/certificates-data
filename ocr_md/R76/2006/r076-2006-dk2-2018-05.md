**Software**

The legally relevant software has version 01.xx, where x reflecting non-legally relevant changes. The software version is displayed as part of the power-up sequence.

**Digital load cells**

The following digital load cells are supported by FT-111 panel / FT-112 panel,

- BR030SD/BR032SD from Baykon
- RC3D from Flintec
