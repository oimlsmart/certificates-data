## Descriptive annex

**Characteristics**

- Accuracy class: &nbsp;III and III
- Weighing range: &nbsp;Single-interval, multi-range (2 ranges) or multi-interval (2 partial intervals)
- Maximum capacity (Max): &nbsp;&nbsp;&nbsp;&nbsp;≤ 600 000 kg
- Maximum number of Verification
- Scale Intervals: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;≤ 10000 for single-interval
  &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;≤ 2x10000 for multi-range and multi-interval
- Maximum tare effect: &nbsp;&nbsp;&nbsp;≤ -Max within display limits
- Fractional factor: p'i = 0.5
- Minimum input voltage per VSI: &nbsp;&nbsp;&nbsp;&nbsp;≥ 0.3 μV
- Excitation voltage: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;5 VDC
- Circuit for remote sense: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;present on the model with 7-terminal connector
- Minimum input impedance: &nbsp;&nbsp;&nbsp;29 ohm
- Maximum input impedance: &nbsp;&nbsp;1200 ohm
- Mains power supply: &nbsp;&nbsp;&nbsp;Gi610: 12 VDC from external supply
  &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Gi650 and Gi620: Either 12 VDC from external supply or 110-240 VAC, 50/60 Hz
  &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Internal or external rechargeable battery (optional)
- Operational temperature: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;-10 °C to +40 °C

**Software**

The software for the indicators is divided into 3 parts – a bootloader, a metrological part and an application part.

Approved version of the bootloader software: FW_BOO_6xx_020. (xx indicates model)<br>
Approved version of the metrological software: FW_WEM_6xx_021. (xx indicates model)

The version name of the application software is build in this form: FW_APP_6xx_yyy.<br>
xx indicates model, yyy indicates the application.

**Devices**

- Initial zero setting device (≤ 20% of Max)
- Semi-automatic zero setting device (≤ 4% of Max)
- Automatic zero setting device (≤ 4% of Max)
- Zero tracking device (≤ 4% of Max)
- Zero indicator
- Stable equilibrium indicator
- Semi-automatic subtractive tare device
- Preset tare device
- Net indicator
- Gross / Net indication
- Counting device
- Gravity compensation
- Printing
- Extended resolution device
- Alibi memory

**Interfaces**

- RS232C
- RS485
- Ethernet
- CAN bus (Gi650 only)
- USB (Gi620 and Gi650 only)
- WiFi

The interface does not have to be secured.
