**DESCRIPTIVE ANNEX**

<u>Characteristics of the instrument:</u>

The Flinttec NuBorne Infant Warmer 500 is a class III, mains operated, self-indicating, single-interval, non-automatic weighing instrument designed to be used as an infant weigher and warming bed.

<u>Construction:</u>

- Steel frame on wheels, with electronic height adjustment
- Canopy with a radiating heat lamp
- Plastic bed compartment containing weighing platform and patient mattress
- Weighing platform under patient mattress comprising four load cells, analogue to digital converter, and microcontroller; providing a digital weight signal to the user interface
- Manual, longitudinal tilt adjustment of bed compartment
- Bubble level indicator (longitudinal only)
- User interface with LCD display, push button controls, and 3 x seven-segment displays showing temperature and heat lamp setting.
- Pedals to adjust the height of bed compartment

<u>Devices:</u>

- Subtractive tare balancing device
- Net indicator
- Gravity compensation
- Short term data storage

<u>Operation:</u>

The NuBorne Infant Warmer 500 is primarily used as an infant warmer therefore does not display live weights but indicates the result of the latest weigh function (tare balancing).

To weigh the infant, the scale button is pressed. An icon instructs the operator to lift the infant off the mattress; at least 250 g must be lifted from the mattress. Once the scale is tared, a signal sounds and an icon instructs the operator to replace the infant, the net weight is then displayed.

Previous weights can be displayed by pressing the trend button.

<u>Load cell:</u>

The instrument is fitted with four load cells, type Planar Beam, E<sub>max</sub> = 7.5 kg, manufactured by Flinttec.

<u>Software:</u>

The software is split across three boards, all software is embedded and supplied as compiled executable code. The scale board software designated SB is held on the weigh platform, it handles the main metrological functions and provides a digital weight value to the display board. The display board software designated DB handles the display of legally relevant data and rounding. The control board designated CB handles the communication interface with the scale board and interlocks. No legally relevant parameters can be affected through the user interface.

The software identification is displayed at boot-up and is shown below for verification purposes:

<table border="1" width="50%">
  <tr><td align="center">Software module</td><td align="center">Version number</td></tr>
  <tr><td align="center">SB</td><td align="center">1.2</td></tr>
  <tr><td align="center">DB</td><td align="center">12.x.x</td></tr>
  <tr><td align="center">CB</td><td align="center">9.x.x</td></tr>
</table>

With ’x’ reflecting non-legally relevant changes.

The SB software and parameters can only be affected by connecting directly to the PCB.

A CRC32 checksum is calculated over the DB and CB at verification and compared against values calculated upon every boot-up. If the checksum values do not match, the instrument will not continue to boot-up. Any software or parameter change will cause the checksum to change.

<u>Interfaces:</u>

- Skin temperature sensor

<u>Sealing:</u>

Access to the scale board, load cell and A/D converter is prevented by tamper evident labels over the securing screws and communication port of the weighing module.

Matching serial numbers can be found on the data plate and weighing module.

<u>Alternatives:</u>

There are currently no authorised alternatives.
