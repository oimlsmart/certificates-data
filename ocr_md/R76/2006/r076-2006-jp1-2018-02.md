## DESCRIPTIVE ANNEX

**Characteristics of the instrument:**

The HV model is a class III, self-indicating, multi-interval instruments non-automatic weighing instrument. The instruments are not designed for direct sales to the public.

**Device:**

- Semi-automatic zero-setting (≤4% of Max)
- Zero-tracking (≤4% of Max)
- Semi-automatic subtractive tera weighing (T = - Max)
- Preset tare
- Zero indicator
- Indication of stable equilibrium
- Printing (The HV-..KCP is built in)

**Interfaces:**

- Serial data interface RS232C (to connect Printer)
- USB interface (to connect Personal computer)
- Comparator output / switch input interface

**Software:**

The legally relevant software is designated version P-1.xx, with x reflecting non-legally relevant changes.

**Sealing:**

Access to the load cell, electronics and calibration switch is prevented by a tamper-evident lead and wire type seal.
