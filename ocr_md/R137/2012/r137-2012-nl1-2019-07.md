## Gas meter configuration

Model 3414 Model 3414 is equipped with 4 measuring paths in a horizontal configuration.

Model 3415 Model 3415 contains a model 3414 path layout and electronics. The model 3415 is additionally equipped with one check path which is connected to a separate set of electronics.

Model 3416 Model 3416 contains a model 3414 path layout and electronics. The model 3416 is additionally equipped with one check path and one diagnostic path which are connected to a separate set of electronics.

Model 3417 Model 3417 is composed of two model 3414 electronics and transducers built into a model 3417 spool piece. The meter can be used in the following configurations:

1. Two separate gas meters

2. Pay / check configuration

Model 3418 Model 3418 is equipped with 8 measuring paths in a horizontal configuration.
